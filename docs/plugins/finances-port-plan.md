# Finances' port — where it stands and what is left

Plugin: `zeff-plugins/plugins/finances-ext`, generated by `scripts/port-finances.mts` from the built-in's own pure cores (plans, insights, recurring, noise,
the cases' core), so the figures are the built-in's by construction. Nothing of it has been run yet — `tests/finances-ext.test.ts` is written, not run.

## Done (as plugin lambdas, no code in the kernel that belongs to Finances)

| Piece | How |
|---|---|
| 16 Kennzahlen (10 debt ones, income, spending, credit accounts, free a month, savings rate, debt-service rate) | metrics answered by the lambda `finances.metric` (`contributes.metrics`: `lambda` + `args`) |
| Widget *Payments coming up* | lambda `finances.widget-payments`, takes over `finances.payments` |
| Widget *Cashflow ahead* | lambda `finances.widget-cashflow`, takes over `finances.cashflow` |
| Source *recurring* (contracts and subscriptions off the statements) | lambda `finances.recurring`, stands in for the built-in's (`replaces`, `lockedFields`) |
| Source *debts* (the cases' debts) | lambda `finances.debts` over the cases and their parties (adopted tables, read only) |

General pieces the kernel gained for it (nothing of Finances in them): `db.cells`, `bank.bookings`, `workspace.value`, `workspace.value-sources`,
`pref.get` (only `ADOPTABLE_PREFS`), `people.by-iban`, metrics by lambda, a source's `lockedFields`, a person field's ids in a source's record.

## Decided and built (2026-11-15)

- **Formulas** — option (b): `contributes.personFormulas` (a snapshot a lambda keeps, read by the formula at once). Finances: `Schulden`, `Forderungen`, `Rate`
  over the lambda `finances.formula`.
- **Subscriptions widget** — a widget's `actFlow` (a flow of the plugin's package, allowed to write): `finances.add-subscription` (`finances.package.json`).
  The lambdas `finances.widget-subscriptions` and `finances.subscription-row` do the reading; `db.add` writes the row.

- **Kennzahlen keep the built-in's names** (`replaces: "finances"` on each metric: the built-in's counts while it is installed, the plugin's take over after the
  switch, so pages and formulas that read `kennzahl("Tilgungsrate")` go on). The widget *Debts in figures* is the kernel's `metrics.stats` with Finances' picks.
  All four widgets are done.
